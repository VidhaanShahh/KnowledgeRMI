🔢 Lamport Logical Clocks

Causal ordering of events across distributed nodes — every RMI call increments the clock

Lamport's Rule: On each event, increment local clock. On message receive: clock = max(local, received) + 1

💡 Why Clock Sync Matters in Our RAG Knowledge Base

📄
Document Upload Ordering
When multiple documents are uploaded across distributed nodes, Lamport clocks guarantee a consistent total ordering — even if physical clocks disagree on wall-clock time.
🔍
Query-Upload Causality
If a query is issued after a document upload, the Lamport timestamp of the query is guaranteed to be greater — ensuring the query can always "see" that document's chunks.
⏱️
Consistent Timestamps
Cristian's Algorithm ensures the HTTP Bridge and RMI Server agree on when events happened — critical for accurate "uploaded at" timestamps stored in MySQL.
🔗
Distributed Audit Trail
Every RMI operation (upload, query, sync) carries a Lamport timestamp, creating a verifiable causal chain of all operations across the distributed system.
